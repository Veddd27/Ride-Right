# Uber Fare Prediction

## Objective
Predict taxi fare using machine learning.

## Dataset
Uber Fare Dataset (NYC-based)

## Features Used
- Distance (Haversine)
- Hour
- Day of Week
- Month
- Passenger Count
- Peak Hour Indicator

## Models Used
- Linear Regression
- Random Forest
- XGBoost
- Gradient Boosting / LightGBM

## Evaluation Metrics
- RMSE
- MAE
- R² Score
